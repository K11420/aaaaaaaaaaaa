# 🐺 人狼ゲーム (Werewolf Game)

ウェブベースのリアルタイム人狼ゲームです。Socket.IOを使用してリアルタイム通信を実現しています。

## 🎮 機能

### 基本機能
- **プレイヤー数**: 3〜15人
- **役職**: 人狼、占い師、騎士、村人（設定可能）
- **ゲームフェーズ**: 昼議論 → 投票 → 夜アクション
- **勝利条件**: 標準ルール
  - 村人陣営: 人狼を全滅させる
  - 人狼陣営: 村人と同数以上になる

### 特徴的な機能
- ✅ ルーム作成・参加機能
- ✅ 役職の自動配布（ホストが設定可能）
- ✅ リアルタイムチャット
- ✅ 投票システム
- ✅ 夜のアクション（襲撃・占い・護衛）
- ✅ CPUプレイヤー（AI）機能
- ✅ 自動勝敗判定
- ✅ ゲームログ表示

## 🤖 CPUプレイヤー（AI）について

- ホストがCPUプレイヤーを追加可能
- CPUは自動で投票・夜アクションを実行
- CPUは定期的にチャットで発言
- 少人数でもゲームを楽しめる

npm install

```bash

npm install
```

## 🚀 起動方法

### 1. サーバーを起動
```bash
cd server
npm start
```
サーバーは `http://localhost:3001` で起動します。

### 2. クライアントを起動
```bash
cd client
npm run dev
```
クライアントは `http://localhost:3000` で起動します。

### 3. ブラウザでアクセス
`http://localhost:3000` をブラウザで開いてプレイを開始！

## 🎯 遊び方

### 1. ルームの作成
1. プレイヤー名を入力
2. 「ルームを作成」をクリック
3. ゲーム設定を調整（任意）
   - 最大プレイヤー数
   - 人狼の数
   - 占い師の数
   - 騎士の数
4. CPUプレイヤーを追加（任意）
5. 「ゲーム開始」をクリック

### 2. ルームに参加
1. プレイヤー名を入力
2. ルームIDを入力
3. 「ルームに参加」をクリック

### 3. ゲームの流れ

#### 昼フェーズ（議論）
- プレイヤー同士でチャットして情報交換
- 誰が人狼か推理する

#### 投票フェーズ
- 処刑したいプレイヤーに投票
- 最多得票者が処刑される

#### 夜フェーズ
- **人狼**: 村人を1人襲撃
- **占い師**: プレイヤー1人を占う（人狼か判定）
- **騎士**: プレイヤー1人を守る（襲撃から保護）
- **村人**: 何もできない

### 4. 勝利条件
- **村人陣営の勝利**: 人狼を全て追放
- **人狼陣営の勝利**: 人狼が村人と同数以上になる

## 🎨 役職説明

| 役職 | 陣営 | 能力 |
|------|------|------|
| 🐺 人狼 | 人狼陣営 | 夜に村人を襲撃できる |
| 🔮 占い師 | 村人陣営 | 夜に1人を占い、人狼か判定できる |
| 🛡️ 騎士 | 村人陣営 | 夜に1人を守り、襲撃から守れる |
| 👤 村人 | 村人陣営 | 特殊能力なし。議論と投票で貢献 |

## 🔧 カスタマイズ

### サーバーポートの変更
`server/index.js` の `PORT` を変更

### クライアント側のSocket.IO接続先変更
`client/.env` ファイルを編集
```
VITE_SOCKET_URL=http://your-server-url:3001
```
