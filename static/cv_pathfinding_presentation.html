核心技術：画像特徴分析

📊 多次元特徴抽出アルゴリズム

🎨 色分布分析

  • HSV色空間変換: 色相・彩度・明度分離
  • K-means色分類: 主要色の自動検出
  • 色複雑度評価: 色分散・支配的色数

📐 構造分析

  • 輪郭検出: 有意な構造物の識別
  • 矩形性評価: 建物図面らしさの定量化
  • 連結成分分析: オブジェクト分離

🔍 エッジ・テクスチャ分析

  • Cannyエッジ検出: 境界線の密度測定
  • Sobelエッジ強度: 方向別エッジ評価
  • 局所テクスチャ: パターン複雑度

🧮 総合複雑度計算

複雑度 = Σ(特徴値 × 重み) • 色複雑度: 25% • エッジ密度: 20% • テクスチャ: 15% • 構造複雑度: 20% • 色数: 10% • 矩形性: 10%

計9種類の二値化アルゴリズムから画像特徴に最適なものを自動選択

高度な二値化処理アルゴリズム

🔧 従来手法 (5種)

  • Otsu法
    ヒストグラム解析による自動閾値
  • 適応的閾値
    局所領域での動的調整
  • 単純閾値
    固定値による基本二値化
  • マルチレベル
    複数段階での段階的処理

🚀 新開発手法 (4種)

  • フロアマップ特化
    HSV前処理 + エッジ強化の組み合わせ
  • カラーマップ用
    ガンマ補正 + ヒストグラム平坦化
  • エッジ強化二値化
    Canny + 適応的閾値の融合
  • 輪郭ベース
    複数閾値での輪郭検出最適化

🔄 フロアマップ特化処理フロー

1. HSV色空間変換 → 明度情報分離 2. ガンマ補正(γ=1.5) → コントラスト調整 3. CLAHE処理 → ヒストグラム均等化 4. Canny + 適応的閾値 → エッジ境界検出 5. モルフォロジー演算 → ノイズ除去・領域修復

経路探索アルゴリズム最適化

🎯 画像特性による自動アルゴリズム選択

BFS

最高速・最短経路保証

小画像・単純経路に最適

A*

ヒューリスティック探索

大画像・複雑経路に効率的

Dijkstra

重み付き最短経路

コスト考慮が必要な場合

📊 選択基準

  • 画像サイズ: 総ピクセル数
  • 通路密度: 通行可能領域の割合
  • 構造複雑度: 経路の入り組み度

⚡ 性能最適化

  • 8方向移動: 斜め移動対応
  • 距離重み付き: 直進1.0、斜め1.414
  • メモリ効率化: 大画像での省メモリ実装
